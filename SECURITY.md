# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please **do not** open a public GitHub issue.

Instead, report it via email:

**Contact:** [vkreg108@gmail.com](mailto:vkreg108@gmail.com)

Please include the following in your report:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant logs, screenshots, or proof-of-concept code

You can expect an acknowledgment within **48 hours** and a resolution timeline will be communicated after the initial assessment.

## Security Best Practices

This project handles financial data and user accounts. We take security seriously and ask that all contributors:

- Never commit credentials, API keys, or secrets to the repository
- Follow OWASP Top 10 guidelines when contributing code
- Use parameterized queries and avoid raw SQL
- Validate and sanitize all user inputs
